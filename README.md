# CYBER-CAREER-TRACKER

As a Japanese American, I’ve always wanted to work overseas. After interning in Japan and the U.S., I built this project to explore and track opportunities across both countries.

This is a centralized dashboard for managing job applications, academic programs, and career progress. It includes AI-powered parsing to make logging information faster and easier.

I hope this tool is helpful for others looking for cybersecurity opportunities in the U.S., Japan, or other parts of the world.

---

## Before You Start

Make sure you have these installed:

| Tool | Check | Download |
|------|-------|----------|
| **Git** | `git --version` in terminal | [git-scm.com](https://git-scm.com) |

If those commands return a version number you're good. If not, download and install them first.

---

## How to Run

Copy and paste these into your terminal **one line at a time:**

```bash
git clone https://github.com/yourusername/cyber-career-tracker.git
```
```bash
cd cyber-career-tracker
```
```bash
ls
```
```bash
open cyber_tracker.html
```


Then open your browser and go to the link your terminal shows — it will look like this:

> ⚠️ Keep the terminal running while you use the app. Closing it stops the server.

## Something Not Working?

| Error | Fix |
|-------|-----|
| `npm install` fails | Make sure you ran `cd cyber-career-tracker` first |
| Blank white screen | Press F12 in browser → Console tab → check for errors |
